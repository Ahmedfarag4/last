The Apollo 11 manga appears under **Mission Archives → Apollo → Apollo 11 → Mission Media**.

The optimized WebP assets are distributed in `apollo_manga_7_chapters_for_github.zip`. The ZIP was generated from the owner's supplied original PDFs and two summary images. **Binary assets still need to be uploaded to GitHub.**
