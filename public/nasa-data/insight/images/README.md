# InSight NASA image assets

Upload the four NASA/JPL photographs from `insight_images_for_github.zip` into this directory using GitHub **Add file → Upload files**.

Required filenames:
- `PIA22876.jpg`
- `PIA22977.jpg`
- `PIA23249.jpg`
- `PIA25287.jpg`

These exact filenames are referenced by `components/game/archives/insight-archive-section.tsx` in the Mission Media gallery. Do not upload the ZIP as-is.
