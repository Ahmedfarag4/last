# InSight Manga — English

The project-team-supplied InSight manga has 4 PDF chapters, each with 5 pages (20 pages total).
The manga is accessible under **Mission Archives → InSight → Mission Media**, above the official NASA photo gallery.

The binary WebP chapter pages are **not uploaded yet**. Download and unzip `insight_manga_20_pages_for_github.zip` from the ChatGPT handoff. Then upload the 20 WebP files to:

```
public/nasa-data/insight/manga/
├── chapter-01/page-01.webp ... page-05.webp
├── chapter-02/page-01.webp ... page-05.webp
├── chapter-03/page-01.webp ... page-05.webp
└── chapter-04/page-01.webp ... page-05.webp
```

Use **Add file → Upload files** inside each chapter directory. Upload file contents, not the ZIP.

The illustration summary mosaic supplied by the project owner is not a fifth chapter; it may be used for promotion separately. The original PDFs are source material and are not served as the optimized game reader.

The reader intentionally identifies this content as illustrated storytelling rather than NASA mission photography or original scientific data.
